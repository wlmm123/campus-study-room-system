# 校园自习室分布式预约管理系统

## 一、项目简介
本项目为一套校园自习室分布式预约管理系统。支持学生在线查询自习室与座位、预约、签到、取消预约；支持管理员维护自习室与座位、管理订单与违约记录。系统通过消息通知实现预约超时提醒与座位自动释放，采用双节点分布式部署，重点验证“部分子系统宕机，其余业务可继续运行”的容错能力。

## 二、双节点与端口规划（核心架构）
| 节点 | 部署内容 | 端口 | 数据库 |
| :--- | :--- | :--- | :--- |
| 节点A（宿主机） | 前端、身份权限子系统、座位资源子系统 | 8081、8082 | auth_db、room_seat_db |
| 节点B（虚拟机） | 订单流转子系统、监控消息通知子系统 | 8083、8084 | order_db、notify_db |

*节点之间通过局域网 IP 进行 REST 远程调用，禁止跨子系统直连数据库。*

## 五、协作规范（契约先行）
1. 全员严格遵循 `04_项目文档/03_小组开发契约.md` 及 `04_REST接口契约.md`。
2. **分支规范：** 写代码严禁直接在 `main` 分支提交，必须拉取自己的 `feature/xxx` 分支，开发测试完毕后合并。
3. **硬性约束：** 禁止跨子系统直连数据库；接口统一加 `@CrossOrigin`；禁止硬编码 `localhost`。
