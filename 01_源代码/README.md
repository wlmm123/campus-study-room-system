## 三、三条硬性约定

1. **不要在 `01_源代码/` 根下新建业务工程**。新建工程一律落在对应子系统目录内，并**直接摊平放**（不套 `xxx-service/` 子目录），例如 8082 就是：
   ```
   子系统2_自习室座位资源子系统/
   ├── pom.xml
   └── src/
   ```
2. **源码目录里不放构建产物**。`target/`、`node_modules/`、`dist/` 已被 `.gitignore` 忽略；
   要给成员6 的东西放 `00_可执行部署包/<服务名>-<版本>/`。
3. **`config/` 不入库**。外置的 `jwt.secret`、`internal.token`、数据库口令只放本机 `config/`，
   仓库里只保留 `deploy/*.template`。启动统一用：
   ```bash
   java -jar xxx-service-1.0.0.jar --spring.config.additional-location=./config/
   ```
