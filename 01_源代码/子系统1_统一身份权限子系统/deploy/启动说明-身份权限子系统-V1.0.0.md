## 二、启动命令

```bash
java -jar auth-service-1.0.0.jar --spring.config.additional-location=./config/
```

> ⚠️ 参数是 `additional-location`（追加），**不能写成 `location`**（覆盖会让 jar 内默认配置全失效）。
> 本机开发调试可再追加 `--spring.profiles.active=local`，此时数据库地址走 `config/application-local.yml` 的 127.0.0.1。

## 二·补、随包脚本（命名遵循《小组开发契约》2.2 `<子系统名>-<版本>` 形式）

本包内置 3 个脚本，双击即可，不依赖命令行环境变量：

| 脚本名 | 用途 | 等价命令 |
| --- | --- | --- |
| `启动脚本-身份权限子系统-V1.0.0.bat` | 节点A 部署启动（走 `config/application.yml`） | `java -jar auth-service-1.0.0.jar --server.port=8081 --spring.config.additional-location=./config/` |
| `启动脚本-身份权限子系统-V1.0.0-本机调试.bat` | 开发机自测（追加 `profile=local`，连 127.0.0.1） | 上面 + `--spring.profiles.active=local` |
| `停止脚本-身份权限子系统-V1.0.0.bat` | 释放 8081：把占用端口的进程杀掉（含无窗口的 `javaw`） | `netstat -ano \| findstr :8081` → `taskkill /F /PID <pid>` |
| `获取Token-身份权限子系统-V1.0.0.bat` | 服务起来后一键打印学生/管理员两个 Token | 两次 `POST /api/auth/login` 后解析 `data.token` |

> ⚠️ **不要直接双击 `auth-service-1.0.0.jar` 启动**。Windows 会用 `javaw.exe` 无窗口方式拉起它，
> 既不读外置 `config/`、也不带 `profile=local`，还会静默占住 8081，导致脚本启动时报
> `Port 8081 was already in use`，而你在任务栏上找不到任何窗口可关。要停就双击「停止脚本」。

脚本内部逻辑（三个脚本一致）：

1. `cd /d "%~dp0"` 先切到 jar 所在目录，避免从别的路径双击导致找不到 `config/`；
2. JDK 选择顺序：`JAVA_HOME` → 本机 `E:\tools\jdk11` → 系统 `PATH` 里的 java；
3. 显式传 `--server.port=8081`，命令行参数优先级最高，避免被环境里同名变量顶掉端口。

> **脚本内容必须是纯 ASCII**：`cmd.exe` 在中文 Windows 下按 GBK 解析 `.bat`，文件若存为 UTF-8 中文，
> 首行 `REM` 注释会被截断成非法命令，出现一堆 `'xxx' is not recognized` 报错。脚本名可以用中文，内容不行。

## 三、必须外置覆盖的配置项

| 配置项                               | 说明                                        |
| --------------------------------- | ----------------------------------------- |
| `spring.datasource.url`           | 指向本节点 `auth_db`，含 `serverTimezone=Asia/Shanghai` |
| `spring.datasource.username`      | MySQL 账号                                  |
| `spring.datasource.password`      | MySQL 口令                                  |
| `server.port`                     | 8081（如端口冲突需改，同时通知全员）                       |
| `jwt.secret`                      | **四端必须完全一致**，否则全员 401                     |
| `jwt.expire-seconds`              | 默认 7200，与契约 4.1.2 `expiresIn` 对齐         |
| `internal.token`                  | **四端必须完全一致**；8081 目前无内部接口，保留配置位与其余三端对齐   |
| `remote.*`                        | 跨节点地址（8081 当前不主动调下游，预留）                   |

## 五、启动后自检（冒烟用）

```bash
# 1. 学生登录（预期 code=200，返回 token 与 role=STUDENT）
curl -X POST http://127.0.0.1:8081/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"20230001","password":"Password123!"}'

# 2. 管理员登录（预期 role=ADMIN）
curl -X POST http://127.0.0.1:8081/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"Password123!"}'

# 3. 带 Token 取当前用户（预期 code=200）
curl http://127.0.0.1:8081/api/auth/me -H "Authorization: Bearer <token>"

# 4. 管理员接口用学生 Token（预期 HTTP 403）
curl http://127.0.0.1:8081/api/admin/roles -H "Authorization: Bearer <学生token>"

# 5. 不带 Token（预期 HTTP 401）
curl http://127.0.0.1:8081/api/auth/me
```

## 六、本模块接口清单

| 方法   | 路径                              | 鉴权       | 说明           |
| ---- | ------------------------------- | -------- | ------------ |
| POST | `/api/auth/register`            | 无        | 学生注册         |
| POST | `/api/auth/login`               | 无        | 登录，签发 JWT     |
| GET  | `/api/auth/me`                  | Bearer   | 当前登录用户信息     |
| PUT  | `/api/admin/users/{userId}/role` | ADMIN    | 分配角色（物理删旧+插新） |
| GET  | `/api/admin/users`              | ADMIN    | 用户分页查询（学号模糊） |
| GET  | `/api/admin/roles`              | ADMIN    | 角色下拉列表       |

## 七、JWT 口径（其余三端照此验签）

```
sub     = userId（字符串）
userId  = userId（数字）
roles   = 角色数组，如 ["STUDENT"] / ["STUDENT","ADMIN"]
role    = 主角色，多角色时 ADMIN > STUDENT
exp     = 签发时间 + 7200 秒
```

> 8082/8083/8084 本地验签即可，**不要回调 8081**；判管理员看 `roles` 数组是否含 `ADMIN`，不要只看 `role`。
