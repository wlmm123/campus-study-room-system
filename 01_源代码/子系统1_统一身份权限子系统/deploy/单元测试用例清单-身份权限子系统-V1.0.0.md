## 二、用例明细

### 2.1 JwtUtilTest（4 例，验证契约 1.3「JWT 必须携带 roles 数组」）

| 编号 | 用例名称 | 输入 / 前置 | 关键断言 | 结果 |
|---|---|---|---|---|
| UT-JWT-01 | 签发的 Token 解析后能看到 userId、roles 数组、主角色 | `generateToken(1L, ["STUDENT"])` | `userId=1`；`roles` 数组含 `STUDENT`；`role=STUDENT`；`isAdmin=false` | 通过 |
| UT-JWT-02 | 多角色时主角色按 ADMIN > STUDENT，且 roles 数组两个都在 | `generateToken(2L, ["STUDENT","ADMIN"])` | `role=ADMIN`；`roles.size()=2`；`isAdmin=true` | 通过 |
| UT-JWT-03 | 换一个密钥签发的 Token 必须验签失败 | 用 secret A 签发，用 secret B 解析 | 抛 `JwtException` | 通过 |
| UT-JWT-04 | 未配置 jwt.secret 时启动即失败 | `JwtProperties.secret` 为空 | `init()` 抛 `IllegalStateException` | 通过 |

### 2.2 AuthServiceImplTest（6 例，验证登录/注册的业务码口径）

| 编号 | 用例名称 | 输入 / 前置 | 关键断言 | 结果 |
|---|---|---|---|---|
| UT-AUTH-01 | 登录成功：签发 Token 并返回主角色 STUDENT、expiresIn=7200 | 账号存在、密码匹配、角色 `[STUDENT]` | `token` 非空；`tokenType=Bearer`；`expiresIn=7200`；`role=STUDENT` | 通过 |
| UT-AUTH-02 | **密码错误：业务码 2001** | 账号存在、`passwordEncoder.matches` 返回 false | 抛 `BusinessException`，`code=2001` | 通过 |
| UT-AUTH-03 | 账号不存在：与密码错误同码 2001 | `selectOne` 返回 null | 抛 `BusinessException`，`code=2001` | 通过 |
| UT-AUTH-04 | 账号被禁用：业务码 2002 | `status=0` | 抛 `BusinessException`，`code=2002` | 通过 |
| UT-AUTH-05 | 学号重复注册：业务码 2003 | `selectCount` 返回 1 | 抛 `BusinessException`，`code=2003` | 通过 |
| UT-AUTH-06 | 注册成功：默认绑定 STUDENT 角色并返回新用户 ID | 学号不存在、角色表查到 `STUDENT` | 返回 `userId=10`，非空 | 通过 |

| 契约条款 | 覆盖用例 |
