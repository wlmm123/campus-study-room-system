# 身份权限子系统（8081）· 本机自测全流程

> 适用：成员1 在自己的 Windows 机器上，从零把那 6 个接口验一遍，并产出给全组的两个 Token
> 环境：JDK 11（`E:\tools\jdk11`）、MySQL 8（本机 3306）、`auth_db` 已初始化
> 产出物目录：`01_源代码/00_可执行部署包/auth-service-1.0.0/`

---

## 0. 前置检查（30 秒）

打开 `cmd`（Win+R → 输入 `cmd` → 回车），依次执行：

```bat
chcp 65001
netstat -ano | findstr ":8081"
```

**期望**：最后一条**没有任何输出**（说明 8081 空闲）。

| 现象 | 处理 |
| --- | --- |
| 有 `LISTENING  <PID>` 输出 | 端口被占。双击部署包里的「停止脚本-身份权限子系统-V1.0.0.bat」，或 `taskkill /F /PID <PID>` |
| 提示没有 mysql 服务 | `net start mysql80` |

## 1. 确认数据库在位（可选，但建议）

```bat
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p -e "use auth_db; select count(*) from sys_user; select count(*) from sys_role;"

**期望**：`sys_user` = 2，`sys_role` = 2。

> 若表不存在：执行 `02_数据库脚本/auth_module.sql`（**只跑自己节点的脚本，别跑 total_init**）。

## 2. 启动服务

进目录 `01_源代码/00_可执行部署包/auth-service-1.0.0/`，**双击**：

```
启动脚本-身份权限子系统-V1.0.0-本机调试.bat
```

> 为什么是「本机调试」这个：它多带 `--spring.profiles.active=local`，数据库走 `config/application-local.yml` 的 `127.0.0.1`；
> 不带后缀的那个是节点A 部署用的，连的是 `10.165.59.231`，本机连不上。

**期望输出（4 行关键信息，缺一不可）**：

```
 JDK     : E:\tools\jdk11
openjdk version "11.0.32.1"            ← ① 必须是 11，不能是 21
 Service : auth-service-1.0.0  |  port 8081  |  LOCAL DEBUG
 The following 1 profile is active: "local"        ← ② profile 是 local
 Tomcat started on port(s): 8081 (http)            ← ③ 端口 8081

⚠️ 这个黑窗口**不要关**，关掉等于停服务。最小化即可。

## 3. 冒烟六步（Postman 或 curl 二选一）

### 3.1 用 Postman

新建一个 Collection `校园自习室-8081`，加 4 个请求：

| # | 方法 | URL | Header | Body | 期望 |
| --- | --- | --- | --- | --- | --- |
| 1 | GET | `http://localhost:8081/api/auth/me` | 无 | 无 | **HTTP 401** |
| 2 | POST | `http://localhost:8081/api/auth/login` | `Content-Type: application/json` | `{"username":"20230001","password":"Password123!"}` | 200，`role=STUDENT`，有 `token` |
| 3 | GET | `http://localhost:8081/api/auth/me` | `Authorization: Bearer <2 拿到的 token>` | 无 | 200，`realName=张三` |
| 4 | POST | `http://localhost:8081/api/auth/login` | 同上 | `{"username":"admin","password":"Password123!"}` | 200，`role=ADMIN` |
| 5 | GET | `http://localhost:8081/api/admin/roles` | `Bearer <4 的 token>` | 无 | 200，返回 2 个角色 |
| 6 | GET | `http://localhost:8081/api/admin/roles` | `Bearer <2 的 token>` | 无 | **HTTP 403** |

### 3.2 用 curl（不想开 Postman 就粘这些）

```bat
:: ① 不带 token，期望 401
curl -i http://127.0.0.1:8081/api/auth/me

:: ② 学生登录，把 token 抄出来
curl -s -X POST http://127.0.0.1:8081/api/auth/login -H "Content-Type: application/json" -d "{\"username\":\"20230001\",\"password\":\"Password123!\"}"

:: ③ 带 token 取当前用户（把 <STU> 换成上一步的 token）
curl -s http://127.0.0.1:8081/api/auth/me -H "Authorization: Bearer <STU>"

:: ④ 管理员登录
curl -s -X POST http://127.0.0.1:8081/api/auth/login -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"Password123!\"}"

:: ⑤ 管理员接口（期望 200）
curl -s -o nul -w "HTTP:%{http_code}\n" http://127.0.0.1:8081/api/admin/roles -H "Authorization: Bearer <ADM>"

:: ⑥ 学生越权（期望 403）
curl -s -o nul -w "HTTP:%{http_code}\n" http://127.0.0.1:8081/api/admin/roles -H "Authorization: Bearer <STU>"
```

### 3.3 一键取两个 Token

服务起着的时候，**双击** `获取Token-身份权限子系统-V1.0.0.bat`，直接打印两个 Token + Postman 头格式。

## 4. 判定标准（对照这张表就算自测通过）

| 检查点 | 期望 |
| --- | --- |
| JVM 版本 | `Java 11.x` |
| 激活 profile | `local` |
| 端口 | 8081 |
| 无 token 访问 `/api/auth/me` | HTTP 401 |
| 学生登录 | `code=200`，`role=STUDENT`，`expiresIn=7200` |
| 学生 token 访问 `/api/auth/me` | `code=200`，`userId=1`，`realName=张三` |
| 管理员登录 | `role=ADMIN` |
| 管理员 token 访问 `/api/admin/roles` | `code=200`，2 条角色 |
| 学生 token 访问 `/api/admin/roles` | **HTTP 403** |
| 密码错误登录 | `code=2001` |
| JWT 解码后的 `roles` | 是**数组**，如 `["STUDENT"]` |

## 7. 常见报错对照表

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `Port 8081 was already in use` | 已有实例在跑（常见于直接双击了 jar，`javaw` 无窗口） | 双击「停止脚本」；`tasklist \| findstr javaw` 可看到隐形进程 |
| `Communications link failure` / `Access denied` | MySQL 没起 / 口令不对 | `net start mysql80`；核对 `config/application-local.yml` 里的用户名口令 |
| `Unknown database 'auth_db'` | 库没建 | 跑 `02_数据库脚本/auth_module.sql` |
| 日志里端口变成一串随机数字（如 64754） | 环境里有 `SERVER__PORT` 之类的同名变量 | 脚本已显式传 `--server.port=8081`，用脚本启动即可 |
| 一堆 `'xxx' is not recognized` | `.bat` 被存成 UTF-8 中文 | 脚本内容必须纯 ASCII；已修好，勿手改编码 |
| 中文日志/提示变乱码 | cmd 代码页 | 先执行 `chcp 65001` |
| `JWT 签名密钥已加载（长度 61 字节）` 后启动失败 | `jwt.secret` 为空或长度不足 | 检查 `config/application.yml` 的 `jwt.secret` 是否与群内统一下发的一致 |
